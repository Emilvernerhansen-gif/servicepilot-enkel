Backup og databeskyttelse

Data ligger i denne browsers lokale IndexedDB, ikke på en fælles server. Sletning af browserdata kan slette dem. Eksportér backup regelmæssigt. Andre kolleger kan ikke se dine data automatisk.

Backup indeholder også uploadede filer. Opbevar den sikkert; import erstatter eksisterende data.
